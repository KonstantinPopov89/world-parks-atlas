# Атлас парков мира

Публичная веб-версия: https://konstantinpopov89.github.io/world-parks-atlas/

Каталог, карта, сравнение, подборки и экспорт XLSX/CSV. Фотографии загружаются из Wikimedia Commons, Flickr и официальной галереи парка; для них нужен интернет. Авторы, первоисточники и условия использования сохранены у каждого снимка. Полный каталог XLSX можно выгрузить в разделе "Операторы и охват".
